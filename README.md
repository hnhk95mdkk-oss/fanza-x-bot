# FANZA → Google Sheets → X 半自動投稿

人が作品と利用可否を確認したうえで、サンプル動画を原則無加工でXへ投稿する構成です。

## 処理順

1. `collect_candidates.py`: 候補収集
2. 人が `利用許可確認=確認済み`、`ステータス=選定済み` に変更
3. `download_and_upload.py`: 国内self-hosted runnerで動画取得、非公開Drive保存
4. `pick_schedule.py`: JSTで1日最大3作品を抽選
5. `post_tweet.py`: 動画＋PR返信を投稿し、60〜90分後に画像返信

## Sheets列

初回実行時にシートがなければ作成します。既存シートの1行目が以下と違う場合は安全のため停止します。

`candidates`: id, 作品名, 女優名, 発売日, キーワード, 商品ページURL, サンプル動画URL, サンプル画像URL1〜4, アフィリエイトURL, 自動生成紹介文, 利用許可確認, ステータス, 収集日時, エラーログ

`schedule`: id, 作品名, Drive動画FileID, Drive動画URL, サンプル画像URL1〜4, アフィリエイトURL, 確定紹介文, 投稿予定日, 抽選済み時刻, tweet3予定時刻, tweet1_id〜tweet3_id, 投稿ステータス, retry_count, 処理中, エラーログ

## 初期設定

1. Google Sheetsと非公開Driveフォルダをサービスアカウントへ編集者共有。
2. README記載の列を作るか、空のブックで各スクリプトを初回実行。
3. GitHub Secretsへ `.env.example` の秘密値を登録。
4. Xの設定「ポストするメディアをセンシティブな内容として設定」をON。
5. X Developer Portalで投稿・メディアアップロード権限と料金を確認。
6. self-hosted runnerは専用ユーザーで必要時のみ起動。ジョブ完了後に停止。

## 重要な運用条件

- `sampleMovieURL` の存在だけでは利用許可済みとは判定しません。FANZAの無料動画ツール等でアフィリエイト利用可能と人が確認したものだけ `確認済み` にします。
- 動画は原則として編集・テロップ・別音声追加を行いません。
- Driveファイルは公開せず、サービスアカウントでAPI取得します。
- `possibly_sensitive=true` は動画ポストと画像ポストの両方に付けます。アカウント側設定も必須です。
- GitHub Actionsのcronは遅延し得るため、抽選時刻以降の最初の15分ジョブで投稿されます。
- API仕様・料金・成人向けコンテンツ規約は運用開始前と定期的に再確認してください。

## 状態遷移

`未選定 → 選定済み（確認済み）→ 投稿待ち → 未投稿 → 動画投稿済み → 投稿済み`

失敗時は `失敗` とエラーログ・retry_countを記録します。部分投稿後もtweet IDを保持するため、成功済みのポストを再送しません。

## 注意

X Media APIのURLや応答形式は変更されることがあります。`X_MEDIA_UPLOAD_URL` で切替可能ですが、最初はテスト用アカウントと1件だけで疎通確認してください。
